# AIチャット管理メモ

AI とのチャット（自分のプロンプトと AI の返答）をコピペして、**チャットの形のまま**保存するメモ帳です。
会話が枝分かれしたら **横並びのレーン** として分岐させ、分岐・付箋・ToDo をすべて **1 ファイル** に保存します。

さらに、記事「How to be more ambitious」の思想（Speed / Altitude / Depth / Range）を作業中ずっと意識できるように、

- 画面上部に常時表示される **「目的の先の目的」** 欄（Altitude の問い）
- 各分岐レーンに付ける **4 軸タグ** と、サイドバーの **軸メーター**（Speed ばかりなら控えめに注意）

を組み込んでいます。

## 開き方

ビルドやインストールは不要です。Chrome または Edge を推奨します。

1. `index.html` をダブルクリックして開く（`file://`）。Chrome / Edge なら `Ctrl+S` の上書き保存も使えるはずです。
   もし保存ダイアログが出ない場合は 2. の方法で開いてください
2. あるいはローカルサーバーで開く（こちらは動作確認済み）

```bash
python3 -m http.server 8787   # Windows では python
```

その後 http://localhost:8787/ を開きます。

> 下書き（自動保存）はブラウザの `localStorage` に、**開いた URL（オリジン）ごと**に保存されます。
> 毎回同じ開き方（ダブルクリックならダブルクリック）で開いてください。

初めて開いたとき（下書きがないとき）は、チュートリアル用の保存例（`js/tutorial.js`：ChatGPT との要件定義チャットを本流＋3 本の分岐に整理したもの）が表示されます。
「新規」で自分のプロジェクトを始められます。小さな例は `sample.aichat.json` を「開く」か、ボードにドラッグ＆ドロップしてください。

### iPad で使う

iPad の「ファイル」アプリから `index.html` を開くとプレビュー表示になり動かないので、Safari で公開版 **https://harutpo.github.io/ai-chat-lanes-app/** を開きます。
公開版は別の public リポジトリ（`harutpo/ai-chat-lanes-app`）で、このリポジトリの履歴は含みません。変更をコミットしたあと `powershell -ExecutionPolicy Bypass -File tools\publish-pages.ps1` で反映します。
Safari の共有ボタン →「ホーム画面に追加」でアプリのように全画面で使えます（ホーム画面版と Safari 版では下書きが別々に保存されます）。

| 操作 | iPad でのやり方 |
|---|---|
| スクロール | 指でなぞる（ペンでも可）。ホバーで出る ✎ ⑂ 📝 などの道具は常に表示されます |
| マーカー | 🖍 マーカーを ON にして **Apple Pencil で文章をなぞる**。引いた線はペンでタップ（または指でタップ）すると消えます。マーカーモード中も指はスクロールのまま |
| 付箋・吹き出しのサイズ | 指でもペンでもドラッグで動かせます |
| 文字入力 | 入力欄では Apple Pencil の手書き入力（スクリブル）も使えます |
| 保存 | 「保存」で共有シートが開くので **「"ファイル"に保存」** → Google ドライブなど保存先を選ぶ。iPad では上書き保存ができないので、毎回保存先を選びます（同じ名前を選ぶと置き換え） |
| 開く | 「開く」→ ファイルアプリから `.aichat.json` を選ぶ |

## 使い方

| 操作 | やり方 |
|---|---|
| メッセージを貼る | レーン下部の入力欄に貼り付け → **追加**（または `Ctrl+Enter`）。役割（自分 / AI）は追加のたびに自動で交互になります |
| 役割を直す | 吹き出しの ⇄ で 自分⇄AI を入れ替え |
| 分岐を作る | 吹き出しの **⑂ 分岐** → 右側に新しいレーンが生え、分岐元から線でつながります |
| 分岐に軸を付ける | レーン見出しの「軸: 未分類」から Speed / Altitude / Depth / Range を選ぶ（色が変わります） |
| 付箋と ToDo | 吹き出しの 📝 で黄色い付箋。付箋内の **+ ToDo** でチェックリスト（`Enter` で次の項目、空欄で `Backspace` → 削除） |
| 付箋を動かす | 付箋の上端（テープ）や余白をドラッグで好きな場所へ。元の吹き出しとはオレンジの点線でつながり、吹き出しと一緒に動きます。ダブルクリックで吹き出しの下に戻す |
| マーカー | ヘッダーの **🖍 マーカー**（または `M`）でマーカーモード → 吹き出しの文章をドラッグすると線が引けます。色は横の丸で選択。引いた線をクリックで消去。`M` / `Esc` で終了 |
| 編集 / コピー | ✎ で本文を編集（`Ctrl+Enter` 確定、`Esc` 取消）。⧉ で生の Markdown をコピー。コードブロックにもコピーボタン |
| 長い返答 | 高さ 500px を超えると自動で折りたたみ。「もっと見る」で展開 |
| ボードを動かす | 方眼紙の空いているところをクリックしたままドラッグ |
| レーンを畳む | レーン見出しの ▾ で細い帯に。▸ で戻す |
| 探す | サイドバーの全文検索。結果をクリックで該当吹き出しへジャンプ（`Enter` で先頭の結果へ） |
| ToDo 一覧 | サイドバーの ToDo タブに未完了の ToDo がレーン別に並びます。ここでチェックも可 |
| 保存 | `Ctrl+S`。初回は保存先を聞かれ、以降は同じファイルに上書き。`Ctrl+Shift+S` で別名保存 |
| 開く | `Ctrl+O`、または `.aichat.json` をボードにドラッグ＆ドロップ（Chrome / Edge では前回開いた・保存したフォルダから始まります） |
| Markdown 書き出し | ヘッダーの「Markdown書き出し」。AI にそのまま貼り直せる読みやすい形になります |

## 保存の仕組み

- **下書き**: 変更のたびに自動で `localStorage` に保存。ブラウザを閉じても次回復元されます。
- **ファイル**: `Ctrl+S` で `プロジェクト名.aichat.json` に保存（中身は JSON）。
  Chrome / Edge では File System Access API により同じファイルへ上書きします。
  非対応ブラウザ（Firefox など）ではダウンロードになります。
- ページを再読込すると「どのファイルに保存していたか」のリンクは切れるため、
  次の `Ctrl+S` では保存先をもう一度選びます（同じファイルを選べば上書きされます）。

### ファイル形式（schema 1）

```json
{
  "schema": 1,
  "title": "プロジェクト名",
  "northStar": "目的の先の目的",
  "laneOrder": ["root", "l_xxx"],
  "lanes":   { "root": { "title": "本流", "axis": null, "parentMessageId": null, "collapsed": false },
               "l_xxx": { "title": "分岐名", "axis": "depth", "parentMessageId": "m_yyy", "collapsed": false } },
  "messageOrder": { "root": ["m_yyy"], "l_xxx": [] },
  "messages": { "m_yyy": { "laneId": "root", "role": "ai", "content": "Markdown 本文",
                           "stickies": [ { "text": "メモ", "pos": { "x": 560, "y": 0 },
                                           "todos": [ { "text": "やること", "done": false } ] } ],
                           "highlights": [ { "start": 0, "end": 6, "text": "マーカー部分", "color": "yellow" } ] } }
}
```

レーン＝一本の線形なチャット。`parentMessageId` が「どの吹き出しから枝分かれしたか」です。

## 野心の 4 軸（分岐タグの意味）

| 軸 | 意味 | こんな分岐に |
|---|---|---|
| **Speed** | 同じ作業をより短時間で | 手順・具体的なやり方を聞く |
| **Altitude** | 抽象度を上げ、作業ではなく結果を問う | 「この先に何が起きてほしい？」「手順を聞かずに済む状態は？」 |
| **Depth** | 一流の専門家の道具・生データ・外部の審判で深くやる | 「一流なら何から始める？」「何が正しさを示す？」 |
| **Range** | 普段使わない分野の知識や手法を持ち込む | 「別の分野の人ならどう見る？」 |

分岐が 3 本以上あり、その 6 割以上が Speed のとき、サイドバーに控えめな注意が出ます。

## 開発

```bash
node --test tests/*.test.js
```

- `js/model.js` … データ層（DOM 非依存。Node からも読める）
- `js/render.js` … 描画・レーン配置・SVG コネクタ・ボード上の操作
- `js/storage.js` … 下書き / ファイル入出力
- `js/app.js` … 起動・ヘッダー・ショートカット
- `js/vendor/` … marked 18.1.1（Markdown）、DOMPurify 3.4.17（サニタイズ）を同梱。オフラインで動きます

## 既知の制限

- 吹き出しのドラッグ並べ替え、レーン間の移動はできません（削除して貼り直してください）
- コードのシンタックスハイライトはありません
- 最近開いたファイルの一覧はありません
